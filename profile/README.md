# ProtocolProbe

Dated facts about the servers in the official MCP registry, from public records, plus readings by an AI model of a server's own text, which are labelled as such. No grade, no rating, and every fact has its source and the day we checked it.

- Directory, reports and API: https://protocolprobe.com
- How we stay neutral: https://protocolprobe.com/principles
- Check your own MCP server, or see which servers are on your machine: [protocolprobe-tools](https://github.com/protocolprobe/protocolprobe-tools)
- The open dataset (CC BY 4.0): https://doi.org/10.5281/zenodo.23386799
- Questions and ideas: [Discussions](https://github.com/protocolprobe/protocolprobe-tools/discussions). A wrong fact: https://protocolprobe.com/contact
